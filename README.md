# aws-iam-users-and-roles
AWS IAM demonstrating user management, group-based access control, IAM policies, and least privilege security principles.
## This project demonstrates the use of AWS identity and Access Management (IAM) to create and manage users, groups, and permissions.
## OBjectives
     - Create IAM users - Create IAM groups - Assign permissions using IAM Policies - Implement least privilege access - Test user access to AWS resources.
## Technologies Used - (AWS IAM) (AWS Management Console) (IAM Policies) (IAM Groups) (User Access Management)
## Tasks completed
    - Explored pre-configured IAM users and groups
    - Inspected IAM policies
    - Added users to groups
    - Verified IAM sign-in URLS'S
    - Tested access restrictions
## Skills Demonstrated
    - Identity and Access Management
    - Security Best Practices
    - Least Privilege Principle
    - AWS adminstration
## Lesson Learned 
IAM is a foundational AWS service used to securely manage access to cloud resources through users, groups, roles, and policies.
